F7 Download Manager

Privacy Policy

Last updated: 10 November 2026

F7 Download Manager (“F7”, “the app”) is a local download manager for Android. It does not require an account, contains no advertising, and includes no analytics or tracking SDKs.

1. Data processed on your device

F7 stores the following locally in the app database and preferences: download URLs and original URLs; file names, MIME types, sizes, progress, segment offsets, and ETags; optional SHA-256 checksums you explicitly compute; schedules you create; app settings; and temporary file handles needed to resume downloads.

This data never leaves your device except as described below. Uninstalling the app removes its database and preferences.

2. Network connections

  • For a download, F7 sends HTTP requests (including Range requests, and cookies/referer/user agent when the link came from the built-in browser) directly to the server you chose.
  • The browser loads the sites you navigate to using Android WebView.
  • HLS playlists and segments are requested from the media server you select.

F7 does not operate a relay server, proxy, cloud account, or synchronization service. The developer does not receive your URLs, files, browsing history, or settings.

3. Permissions

  • Internet and network state — download files and detect connectivity.
  • Foreground service (dataSync) — keep downloads running in the background with a visible notification.
  • Notifications (Android 13+) — show progress and pause/resume controls.
  • Wake lock — keep the CPU awake only while downloads are active.
  • Receive boot completed — restore schedules after a reboot.

F7 does not request location, contacts, camera, microphone, SMS, phone, or broad storage permissions. Files are written through MediaStore or the Storage Access Framework folder you choose.

4. Advertising, analytics, and sharing

F7 contains no ads, advertising identifiers, analytics SDK, crash reporting SDK, or social SDK. The developer does not sell or share personal data. Android backup is disabled for this app.

5. Children

F7 is a general-purpose utility and does not knowingly collect personal information from anyone, including children. The built-in browser can access third-party websites whose content is outside the developer’s control.

6. Data retention and deletion

All data is local. You can delete individual downloads and files in the app, clear completed downloads in Settings, clear browser data from the browser menu, or uninstall the app to remove all app data. There is no server-side account or data to delete.

7. Security

F7 uses HTTPS where supported, blocks invalid SSL certificates, and disables local file access and JavaScript bridges in the browser. Cleartext HTTP links are supported for compatibility and are flagged before download.

8. Changes and contact

If this policy changes, the date above changes. Material changes appear in release notes. For privacy questions, use the project repository or the developer contact on the Google Play listing. The app itself collects no contact data.
