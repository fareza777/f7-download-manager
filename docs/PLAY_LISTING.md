## Full description

F7 Download Manager & Browser is a lightweight, ad-free download manager for Android. It is
built for people who want a simpler, more reliable experience than desktop-era
download tools — with no account, no subscription, and no server in the middle.

**Download the way it should work**

• Multi-connection downloads — up to 16 parallel connections for servers that
  support Range requests.
• Reliable resume — pause, close the app, or lose the connection and continue from
  the exact byte. Progress is saved continuously.
• Automatic recovery and retry with backoff for unstable networks.
• Large-file friendly: streaming writes, no whole-file buffering, low memory use.
• Background downloads with a foreground service and clear progress notifications.

**Built-in browser**

• Visit a site and let F7 capture download links.
• Cookies, referer, and user agent are passed through so downloads from signed-in
  sites work.
• Secure WebView: no local file access, no JavaScript bridge, blocked mixed content
  and SSL errors.
• Share a link from any app or paste one from the clipboard.

**Organise and control**

• Batch add multiple links at once.
• Queue with configurable concurrency, Wi-Fi-only mode, and a global speed limit.
• Schedules: once, daily, or weekly.
• Categories for video, audio, images, documents, archives, and apps.
• Smart file manager with duplicate detection, SHA-256 checksums, open/share, and
  delete.

**Video**

• Non-DRM HLS (M3U8) VOD downloads, including AES-128 encrypted segments.
• Live playlists and DRM/SAMPLE-AES content are not supported and are rejected
  clearly.

**Premium, readable design**

• Light mode by default with five carefully tuned themes, plus dark and system mode.
• Large default text, responsive layout, compact dashboard, tabbed settings.
• English interface.

**Private by design**

• No ads. No analytics. No account. No tracking.
• Everything is stored on your device.
• Open source under GPL-3.0.

**Good to know**

• Torrent and magnet links are not supported.
• Download speed depends on the server and your network; F7 shows measured live
  speed rather than advertised claims.
• HTTP links are supported but flagged as unencrypted; prefer HTTPS.
• Android may defer scheduled downloads in battery saver; F7 posts a notification
  fallback if it cannot start automatically.
